# Smart-parking-management-system
A C++ based Smart Parking Management System designed to manage parking slots efficiently and reduce manual parking management.

📌 Project Overview

This project allows users to manage parking spaces by adding vehicles, removing vehicles, checking available slots, and displaying parked vehicle details.

✨ Features

- Add vehicle details
- Remove vehicle from parking
- Check available parking slots
- Display parked vehicles
- Manage parking records
- Calculate parking charges

🛠️ Technology Used

- Language: C++
- Concepts: Object-Oriented Programming (OOP)
- IDE: VS Code / Code::Blocks

▶️ How to Run

1. Download or clone this repository.
2. Open the "main.cpp" file in a C++ IDE.
3. Compile the program.
4. Run the program and follow the menu options.

🎯 Objective

The main objective of this project is to provide a simple and efficient computerized solution for managing parking spaces and vehicle records.
